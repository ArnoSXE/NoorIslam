# noorislam

A high-performance, client-side web suite providing essential Islamic spiritual utilities. This project is designed as a centralized hub for daily worship, leveraging modern Web APIs for a seamless, responsive experience across all devices.

## 🚀 Live Demo
[View the Live Site on Vercel](https://noorislam.vercel.app) 

## 🛠 Features

* **Scripture Interface:** Full digitized Quran reader and authenticated Hadith collections.
* **Geolocation Services:** Real-time, location-based Prayer Time calculations.
* **Qibla Projection:** Dynamic compass utility to determine the direction of the Kaaba using browser-based coordinates.
* **Digital Tasbeeh:** An intuitive, session-based counter for daily supplications.
* **Performance First:** Optimized for low-latency and offline-ready accessibility.

## 💻 Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Dark/Neon styling), JavaScript (ES6+)
* **APIs:** Geolocation API for real-time positioning.
* **Deployment:** Vercel (CI/CD via GitHub).
